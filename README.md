# Library-Management-System
A console-based Library Management System built in Java for the CSE2006 – Programming in Java course project. It digitizes book cataloging, member registration, book issue/return with fine calculation, and reporting — all backed by a relational database via JDBC.
How to Run
Make sure Java is installed (`java -version`).
Compile:
   javac -d bin src/\*.java
Run:
   java -cp "bin:lib/sqlite-jdbc-3.46.1.3.jar" Main
